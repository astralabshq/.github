# Security Policy

We take the security of Astra Labs software seriously and appreciate responsible disclosure.

## Reporting a vulnerability

**Please do not report security vulnerabilities through public GitHub issues, discussions, or pull requests.**

Report it privately through GitHub instead:

1. Go to the affected repository's **Security** tab.
2. Click **Report a vulnerability**.
3. Fill in the advisory form.

Please include as much of the following as you can:

- The type of issue (for example: injection, authentication bypass, exposed secret)
- The affected repository, branch, or release
- Steps to reproduce, or a proof of concept
- The impact, including how an attacker could exploit it

## What to expect

- We'll acknowledge your report as soon as possible.
- We'll keep you updated while we investigate and fix the issue.
- Once a fix is released, we're happy to credit you in the advisory if you'd like.

Please give us reasonable time to address the issue before disclosing it publicly.
